# Data attribution

## Code and data rights

The PyOSV Q-QUAL PoC source code is licensed under the Common Public License
Version 1.0 (`CPL-1.0`). That code license does not grant rights to third-party
input data.

The release does not redistribute the raw F3 DAT volumes in either the public
Git repository or its Release assets. Users are responsible for obtaining and
using input data under the terms supplied by the original data provider. Users
must provide data they are authorized to use.

## Compact publication evidence

The compact publication contains F3-derived figures and agreement metrics, not
the raw input volumes. Its manifest records the dataset identity and the source
completion identity used for the reported evidence. The dataset is identified
as `f3d-official-v1`, with shape `(420, 400, 100)` and storage dtype `>f4`.

The F3 public reference is an agreement target and is not geological truth. No
specific Creative Commons subtype is asserted for the underlying F3 data.
